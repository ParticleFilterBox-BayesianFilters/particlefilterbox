# Changelog

## v0.1.0 (2026-03-17)

Initial release.

### Features

- Bootstrap, Auxiliary, EKF, and UKF particle filters
- FFBSm, Two-Filter, and Fixed-Lag smoothers
- SMC Sampler, Tempering, SMC^2, IBIS, Waste-Free SMC
- PMMH, Particle Gibbs, Conditional SMC
- Stochastic Volatility, Local Level, Linear Gaussian, DSGE models
- Comprehensive diagnostics (ESS, weight analysis, convergence)
- Visualization with 4 themes (nodesecon, minimal, paper, dark)
- HTML/LaTeX/Markdown report generation
- CLI tool: pfbox filter/estimate/compare/simulate
- Bundled simulated datasets (finance, macro)
- PFExperiment reproducible experiment framework
- Integration tests validating PF = Kalman (corr > 0.99)
