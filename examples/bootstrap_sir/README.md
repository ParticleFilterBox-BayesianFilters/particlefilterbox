# Bootstrap PF and SIR Examples

## Notebooks

1. `01_bootstrap_pf.ipynb` - Bootstrap Particle Filter basics
2. `02_sir.ipynb` - Sequential Importance Resampling
3. `03_resampling_comparison.ipynb` - Comparison of resampling methods

## Datasets

- `data/simulated_linear_gaussian.csv` - Linear-Gaussian SSM (Kalman benchmark)
- `data/simulated_sv.csv` - Stochastic volatility model

## Validation

- `R_validation/` - R scripts using SMC and pomp packages
- `stata_validation/` - Stata scripts using sspace (linear-Gaussian only)
